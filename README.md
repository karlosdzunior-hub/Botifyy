# Botify 🤖

Telegram-бот BotFactory — платформа для создания Telegram-ботов и Mini Apps через AI-диалог без знания кода.

## Стек
- Python 3.11 + aiogram 3.x
- Groq API (qwen-qwq-32b, llama-3.3-70b, gemma2-9b)
- aiosqlite + SQLite

## Запуск
```bash
pip install -r requirements.txt
TELEGRAM_BOT_TOKEN=... GROK_API_KEY=... python bot/main.py
```

## Функции
- 🤖 Создать бота — AI-диалог, уточняющие вопросы, резюме
- 📱 Создать Mini App
- 📦 Мои боты
- 🖥️ Хостинг (тарифы 399/890/1990 ₽/мес)
- 💳 Кредиты (150 приветственных)
- 👥 Рефералы (+50 кредитов за реферала)
- ❓ Помощь
